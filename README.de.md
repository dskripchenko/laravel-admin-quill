# dskripchenko/laravel-admin-quill

> 🌐 [English](README.md) · [Русский](README.ru.md) · **Deutsch** · [中文](README.zh.md)

Alternative WYSIWYG-Engine auf Basis von Quill (BSD-3-Clause). Gibt html und delta aus. Drop-in-Ersatz für das Standard-WYSIWYG-Feld.

Ein Sister-Pack für [`dskripchenko/laravel-admin`](https://github.com/dskripchenko/laravel-admin).

## Installation

```bash
composer require dskripchenko/laravel-admin-quill
php artisan migrate
```

Das Plugin registriert sich automatisch über Laravel Package Discovery.
